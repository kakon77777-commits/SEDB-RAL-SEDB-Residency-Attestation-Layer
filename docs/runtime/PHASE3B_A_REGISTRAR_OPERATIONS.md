# Phase 3B-A Synthetic Registrar Operations

SEDB-RAL `0.5.0a1` adds provider-free synthetic operations contracts,
workspace/policy binding, durable intake/request/receipt stores, one-winner
leases, Phase 3A engine orchestration, typed no-append unsupported actions,
public export, CLI, and deterministic acceptance.

It never targets the deployed production registry and performs zero private,
network, provider, Fabric-event, or real-applicant effects. R3B-B production
layout activation and R3B-C first applicant remain separate Neo.K gates.

The J1 source pin is fixed to RAL view schema commit `077606f`, 6029 bytes,
SHA-256 `32AEFBB92345538B0320930E237F35791C0C43C5A1F7E40EACE5D7248D803373`.
